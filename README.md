# Squad game downloads

Builds of our co-op squad shooter for Mac and Windows. This repo holds only
the downloads, no source code.

**Download the newest build:** https://github.com/nathanjmetz/squad-game-downloads/releases/latest

- Windows: [SquadGame-Windows.zip](https://github.com/nathanjmetz/squad-game-downloads/releases/latest/download/SquadGame-Windows.zip)
- Mac: [SquadGame-Mac.zip](https://github.com/nathanjmetz/squad-game-downloads/releases/latest/download/SquadGame-Mac.zip)

## Install on Windows

1. Download SquadGame-Windows.zip and unzip it (right-click, *Extract All*).
2. Open the unzipped folder and double-click the game's .exe.
3. If SmartScreen warns you, click *More info*, then *Run anyway*.

## Install on Mac

1. Download SquadGame-Mac.zip and double-click it to unzip.
2. Drag the game app into Applications.
3. The first time, right-click the app, choose *Open*, then click *Open* again.
   On newer macOS, if it still won't open, go to System Settings, then
   Privacy & Security, and click *Open Anyway*.

## Play together

Everyone needs the same build, so grab the newest one before you play. One
player clicks Host, the others click Join and type the host's IP address
(UDP port 7777). The Esc panel shows the address to share. The first time
you host, allow the game through the firewall (Windows: allow on private
networks; Mac: allow incoming connections). HOW_TO_PLAY.txt in the zip has
the controls.
